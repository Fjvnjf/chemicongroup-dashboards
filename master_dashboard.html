📖 Command Center Guide

Navigation: Use the sidebar to switch between modules. The command console at the bottom accepts natural language.

Sample Commands:

update feedstock to $400/ton and rerun DCF — Triggers financial re-calculation

run HAZOP for reactor section — Opens safety analysis

compare scenario A and B — Side-by-side comparison

generate investor update — Creates summary report

find experiments where yield exceeded 0.85 — Queries R&D KB

summarize project status — AI-generated overview

Data Sources: All modules read from DCF Model, Plant Spec, Safety Engine, and EDMS files. Changes made via console are simulated — real execution requires backend deployment.
